# 9. Important Git Workflow Understanding

## Key Realization
There are TWO separate identities:

### A. Git Commit Identity

Controlled by:

```bash
git config user.name
git config user.email
```

This affects:
- commit author
- commit history

### B. Gitea Authentication Identity

Controlled by:
- username/password used during push

This affects:
- PR creator
- branch ownership
- repository permissions

This distinction was deeply discussed and understood.

# 13. Important Git/Gitea Lessons Learned

## A. First Pushed Branch Became Default Branch

Because:
```text
test/auth-check
```

was pushed before `main`.

This caused:
- inability to delete branch
- branch became protected/default

## Resolution
Proper workflow established:

```text
Create main
→ Push main
→ Set default branch
→ Protect main
```

---

# 14. Main Branch Protection

## Important Lesson
Protecting `main` BEFORE first push caused:

```text
Not allowed to push to protected branch main
```

Resolution:
- temporarily remove protection
- push `main`
- set default branch
- re-enable protection
